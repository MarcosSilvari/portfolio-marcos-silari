  • Projeto 1

    • Projeto 1 — Fundamentos de SQL com HTML

    Aplicação prática dos comandos essenciais de SQL (CREATE TABLE, INSERT INTO, INNER JOIN, UPDATE e DELETE), com o código exibido junto do resultado correspondente.

    1. CREATE TABLE — criando as tabelas

    CREATE TABLE clientes (
                        id INT PRIMARY KEY,
                        nome VARCHAR(100),
                        email VARCHAR(100)
                    );

                    CREATE TABLE pedidos (
                        id INT PRIMARY KEY,
                        cliente_id INT,
                        produto VARCHAR(100),
                        valor DECIMAL(10,2),
                        FOREIGN KEY (cliente_id) REFERENCES clientes(id)
                    );

    2. INSERT INTO — inserindo dados

    INSERT INTO clientes (id, nome, email) VALUES
                    (1, 'Maria Silva', 'maria@email.com'),
                    (2, 'João Souza', 'joao@email.com');

                    INSERT INTO pedidos (id, cliente_id, produto, valor) VALUES
                    (1, 1, 'Notebook', 3500.00),
                    (2, 2, 'Mouse', 80.00);

    ID: 1 | Nome: Maria Silva | Email: maria@email.com

    ID: 2 | Nome: João Souza | Email: joao@email.com

    3. INNER JOIN — juntando as tabelas

    SELECT clientes.nome, pedidos.produto, pedidos.valor
                    FROM clientes
                    INNER JOIN pedidos ON clientes.id = pedidos.cliente_id;

    Maria Silva comprou um Notebook no valor de R$ 3.500,00

    João Souza comprou um Mouse no valor de R$ 80,00

    4. UPDATE — atualizando um registro

    UPDATE clientes
                    SET email = 'maria.silva@email.com'
                    WHERE id = 1;

    ID: 1 | Nome: Maria Silva | Email: maria.silva@email.com (atualizado)

    5. DELETE — removendo um registro

    DELETE FROM pedidos WHERE id = 2;

    Pedido #1 - Cliente: Maria Silva - Produto: Notebook - Valor: R$ 3.500,00

    (Pedido #2 foi removido)

  • Projeto 2

    • Projeto 2 — Sistema de Login com Python, SQL e Front-end

    Aplicação web desenvolvida com Flask e SQLite, implementando cadastro e autenticação de usuários com armazenamento seguro de senhas (hash) e formulários HTML integrados ao back-end.

    Python Flask SQLite HTML Autenticação Segurança

    1. Banco de Dados (SQL)

    CREATE TABLE usuarios (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    usuario TEXT UNIQUE NOT NULL,
                    senha TEXT NOT NULL
                );

    2. Back-end (Python / Flask)

    from flask import Flask, render_template, request, redirect
                import sqlite3
                from werkzeug.security import generate_password_hash, check_password_hash

                app = Flask(__name__)

                @app.route('/cadastro', methods=['GET', 'POST'])
                def cadastro():
                    if request.method == 'POST':
                        usuario = request.form['usuario']
                        senha = generate_password_hash(request.form['senha'])

                        conn = sqlite3.connect('banco.db')
                        cursor = conn.cursor()
                        cursor.execute("INSERT INTO usuarios (usuario, senha) VALUES (?, ?)", (usuario, senha))
                        conn.commit()
                        conn.close()
                        return redirect('/login')

                    return render_template('cadastro.html')


                @app.route('/login', methods=['GET', 'POST'])
                def login():
                    if request.method == 'POST':
                        usuario = request.form['usuario']
                        senha = request.form['senha']

                        conn = sqlite3.connect('banco.db')
                        cursor = conn.cursor()
                        cursor.execute("SELECT senha FROM usuarios WHERE usuario = ?", (usuario,))
                        resultado = cursor.fetchone()
                        conn.close()

                        if resultado and check_password_hash(resultado[0], senha):
                            return "Login realizado com sucesso!"
                        else:
                            return "Usuário ou senha incorretos."

                    return render_template('login.html')


                if __name__ == '__main__':
                    app.run(debug=True)

    3. Front-end (HTML do Login)

                        <input type="password" name="senha" id="senha" required><br>
